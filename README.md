# Secure Digital Identity Verification Tool

A lightweight Python module designed to simulate a government digital identity verification platform. It enforces strict format checks for National Identity Numbers (NIN), verifies biometric integrity using SHA-256 hashes, and maintains immutable JSON audit logs.

## Core Features

- **Formal Input Validation:** Validates identity number patterns using regular expressions before processing.
- **Biometric Integrity Assurance:** Hashes biometric inputs to detect tampered or corrupted verification data.
- **Regulatory Audit Logging:** Automatically captures timestamped, structured logs for compliance auditing.
- **Domain-Specific Logic:** Designed around software requirements engineering principles for public sector digital identity systems.
